# agg - 命令行聚合工具

## 概要 (Overview)

`agg` 是一个遵循 Unix 哲学的命令行工具，用于对列式数据进行高效的分组聚合。

它从标准输入或文件读取数据，执行计算，然后将纯净、机器可读的结果输出到标准输出。它被设计为可以轻松地在命令行管道 (pipeline) 中与其他工具（如 `pp`, `sort`, `awk`）协同工作。

## 需求 (Requirements)

- **核心功能**: 基于一个或多个键（key）对数据进行分组，并对指定的数值列执行聚合计算。
- **聚合函数**: 支持多种聚合函数，至少包括 `count`, `sum`, `avg`, `min`, `max`。
- **灵活性**:
  - 支持通过参数灵活定义输入和输出的分隔符。
  - 支持对列的范围（如 `2-5`）进行操作。
- **易用性**:
  - 为最常见的聚合操作提供快捷方式，减少不必要的输入。
  - 参数设计清晰，学习成本低。
- **互操作性**: 输出格式必须是干净、原始的列式数据，以便于管道传递给下一个程序。
- **输入源**: 能够处理来自标准输入或一个或多个文件的输入。

## 规格 (Specifications)

### 用法

```bash
agg [OPTIONS] [FILES...]
```

### 参数

- `-k, --key-cols <SPEC>`
  - **描述**: 指定作为分组依据的一个或多个键列。
  - **`<SPEC>`**: 列索引的组合，用逗号分隔。支持单个索引（`1`）、多个索引（`0,2`）和范围（`0,2-4`）。列索引从 0 开始。

- `-f, --fields <SPEC>`
  - **描述**: 定义需要执行聚合操作的字段和函数。
  - **`<SPEC>`**: 一个或多个聚合定义的组合，用逗号分隔。支持范围。
  - **定义格式**:
    1.  `列号` (例如 `2`): **快捷方式**。对该列执行默认聚合 (`count`, `sum`)。
    2.  `列号:函数` (例如 `2:sum`): **明确形式**。对该列执行指定的聚合函数。

- `-A, --all-aggs`
  - **描述**: 一个开关标志。如果提供此参数，将对所有在 `-f` 中**未明确指定函数**的列执行全部聚合 (`count`, `sum`, `avg`, `min`, `max`)。

- `-d, --delimiter <DELIM>`
  - **描述**: 指定输入数据的字段分隔符。
  - **默认值**: `	` (制表符)。

- `-D, --output-delimiter <DELIM>`
  - **描述**: 指定输出数据的字段分隔符。
  - **默认值**: 与输入分隔符 (`-d`) 相同。

- `--header`
  - **描述**: 一个开关标志。表示输入数据**有**表头行。如果提供此参数，第一行将被视为表头，`agg` 会据此生成新的输出表头。
  - **默认行为**: 默认输入**没有**表头。

- `--no-output-header`
  - **描述**: 一个开关标志。禁止在输出中打印表头行。

- `[FILES...]`
  - **描述**: 零个或多个输入文件名。如果省略，则从标准输入读取。

### 处理规则

1.  **范围展开**: 列范围（如 `2-4`）会被自动展开为单独的列索引（`2,3,4`）。
2.  **默认聚合**: 如果 `-f` 中的定义只包含列号，则应用 `count` 和 `sum` 函数。
3.  **`--all-aggs` 规则**: `-A` 标志仅影响那些未使用 `:函数` 语法的列定义。
4.  **表头**:
    - 使用 `--header` 参数时，`agg` 会读取第一行作为表头，并用它来生成更有意义的输出表头。
    - 默认情况下，或使用 `--no-output-header` 时，不会输出表头。

## 示例 (Examples)

假设存在一个 `data.csv` 文件，内容如下:

```csv
group,user,score,time_ms
A,user1,10,100
A,user2,20,200
B,user1,30,300
A,user1,5,50
```

---

**示例 1: 默认聚合**

对第 2 列 (`score`) 执行默认的 `count` 和 `sum` 聚合，按第 0 列 (`group`) 分组。

```bash
cat data.csv | agg --header -k 0 -f 2 -d ','
```

**输出:**

```
group,count_score,sum_score
A,3,35
B,1,30
```

---

**示例 2: 指定聚合函数**

计算第 3 列 (`time_ms`) 的平均值，按第 0 和 1 列联合分组。

```bash
cat data.csv | agg --header -k 0,1 -f '3:avg' -d ','
```

**输出:**

```
group,user,avg_time_ms
A,user1,75.00
A,user2,200.00
B,user1,300.00
```

---

**示例 3: 混合使用默认与指定聚合**

对第 2 列执行默认聚合，同时计算第 3 列的最小值和最大值。

```bash
cat data.csv | agg --header -k 1 -f '2,3:min,3:max' -d ','
```

**输出:**

```
user,count_score,sum_score,min_time_ms,max_time_ms
user1,3,45,50,300
user2,1,20,200,200
```

---

**示例 4: 使用范围和 `--all-aggs`**

对第 2 到 3 列 (`score`, `time_ms`) 执行所有聚合操作。

```bash
cat data.csv | agg --header -k 0 -f '2-3' -A -d ','
```

**输出:**

```
group,count_score,sum_score,avg_score,min_score,max_score,count_time_ms,sum_time_ms,avg_time_ms,min_time_ms,max_time_ms
A,3,35,11.67,5,20,3,350,116.67,50,200
B,1,30,30.00,30,30,1,300,300.00,300,300
```

---

**示例 5: 禁止输出表头**

读取 CSV，聚合后输出无表头的 TSV。

```bash
cat data.csv | agg --header --no-output-header -k 0 -f 2 -d ',' -D '	'
```

**输出 (字段间为 Tab):**

```
A	3	35
B	1	30
```
